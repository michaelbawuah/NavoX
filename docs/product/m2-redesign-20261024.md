Source: NavoX-Milestone-2-Redesign-Spec.pdf, 19 pages, 24 October 2026.
This supersedes conflicting M2 UI decisions in vox-m2-shell-today.md. Prior M2
engineering checks do not constitute acceptance of this redesign. Sample names,
courses, dates, emails and schedules belong only in clearly marked QA fixtures.
No physical-phone or real-student acceptance is implied by automated checks.

User decision: written 90-minute study-block maximum wins over the two-hour
blocks in the Planner screenshots. Split long work into shorter blocks.
Preserve working Vox playback, interruption, reconnection, private transcripts,
approvals and usage accounting. Picovoice approval remains external.
