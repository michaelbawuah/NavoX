# Milestone 4 memory and privacy: source checkpoint

This is an implemented source increment, not acceptance of Milestone 4 or a
claim of live-provider, physical-phone or student qualification.

## Implemented behavior

- Explicit account-scoped disclosure and retention choice: 30 days, 90 days or
  Never. Omitting the choice or agreement cannot enable history. Reading the
  controls never creates a privacy preference or conversation.
- Encrypted completed-dialogue history for configured Vox speech, typed Vox and
  ordinary typed conversation. Source identity, owner, record and purpose are
  authenticated inside ciphertext. Repeated completion does not duplicate text;
  lossy active-call compaction is not archived as a verbatim transcript.
- Independently visible, encrypted saved facts with source provenance, editing,
  deletion and a separate sensitive-detail agreement. Narrow literal learning (described below) never uses model-generated answers
  or creates sensitive facts automatically. Legacy explicit saved preferences remain
  distinguishable and are covered by Delete everything.
- Off-record calls use worker RAM for heard context and store only a content-free
  revision checkpoint. A replacement worker cannot recover private text. Closing
  the worker clears its private cache. Off-record mode also disables archive and
  saved-memory recall. Changing privacy ends the current call to fence provider
  RAM and queued work.
- Bounded permitted recall: key non-sensitive saved facts at realtime start and
  rollover, the same facts on pipeline speech/typed requests, and a shared past
  subject lookup. Historical excerpts come only from student text; past model
  answers are not promoted to student facts. Current saved corrections are kept
  in context even when the query names the old value. Sensitive saved facts stay
  in Settings, and historical excerpts require a spoken privacy notice.
- Ordinary typed conversation uses the same permitted recall and captures its
  privacy generation before provider work. Forget during provider work rejects
  the stale answer and its history write.
- Search/read/delete history. Search covers the 100 most recently updated
  conversations and discloses that bound in the UI. Saved-fact reads cap at 100;
  voice context caps at 20 facts, one optional thread and three historical matches.
- A natural Forget request prepares a private Settings review, returning up to
  four metadata matches from at most 100 saved items. The model cannot execute
  deletion or approve it. The current agent publishes a private review handoff.
- Source Forget erases transcript, summary and source-derived facts/threads,
  bumps the privacy generation and revokes active media. A content-free source
  tombstone prevents replay. Deleting a source-derived fact also erases
  its source and sibling derivatives after the explicit review. Editing preserves
  its historical transcript and sibling facts, clears its obsolete derived summary
  and makes the corrected fact authoritative. Future recall suppresses that old
  source and its uncorrected sibling facts/threads; History remains readable and
  searchable. Every completed archived turn otherwise has a summary, so a retained
  transcript with no summary is the conservative suppression marker. Manual facts
  have no linked conversation to erase.
- Expiry erases transcripts, summaries and threads while retaining independently
  visible saved facts. The existing independent Vox cleanup process checks a
  bounded expired-owner batch every minute; authenticated history access also
  enforces expiry. Disabling recording or toggling off-record never turns an
  existing 30/90-day expiry into permanent retention.
- Delete everything and student-data reset share the erasure boundary, including
  legacy explicit memory and native assistant sessions. Installed Node runtime
  tables cascade through the native session foreign key in the same database.
  Content-free usage and erasure tombstones remain.

## Bounded automatic learning

Completed retained student turns can now update source-linked facts using closed
literal rules for reply length, tone, study time, programming language, employer
and school. Optional exact Remember that or Actually prefixes use the same rules.
The whole statement must match; questions, quotations, reported speech, conditions,
code, multiple clauses and unknown forms produce no automatic fact. Source text
and turn sequence are preserved. No provider call, new model route, embedding,
raw audio, reminder, calendar change or usage charge is introduced.

Same-category declarations update only automatic facts. Named job departure can
replace an automatic employer only when the named employer matches. Independently
reviewed corrections stay under student control. Old transcripts remain available;
obsolete raw sources are suppressed during future recall.

Recognized literal interview/exam/midterm/presentation/project-review declarations
with today, tomorrow, a weekday or an ISO date can open a thread. Dates use the
student's local date. A generic optional follow-up is eligible only after that
local event date and for seven days afterward. The owner lock durably assigns
one thread to a call/chat context; repeated builds and retries in that context
reuse the same claim, and another context cannot take it. A completed/heard host
answer containing the exact follow-up prompt records responded. Offered-to-model
and host-response receipts are separate; neither proves student delivery or a
successful event. A failure before speech can consume the one-time offer.

Sensitive/crisis/credential exclusion is sticky for the source conversation,
including consecutive completed fragments. A later excluded turn removes earlier
automatic facts and threads from that source while preserving independently
reviewed facts and the permitted transcript. Off-record, missing disclosure,
changed generation, source Forget and expired sources prevent learning through
the same archive transaction. Sensitive historical sources are excluded from
voice past-context lookup.

## Open implementation and qualification

- This is conservative literal learning, not arbitrary semantic/model extraction.
  Unsupported statements require the explicit Settings fact flow. General open
  questions, nuanced corrections and reviewed model-generated candidates remain
  future work. No unqualified or unpriced model route is enabled.
- Keyword sensitivity checks are conservative guardrails, not a comprehensive
  classifier. No automatic sensitive-fact extraction is claimed.
- A separately configured Node runtime database requires its own erasure and
  retention qualification. The native same-database cascade does not establish
  cleanup of an independent database.
- The non-configured legacy one-off voice gateway is not the configured
  cross-call memory path. Raw audio is never added to these memory tables.
- Live model behavior, spoken privacy-warning adherence, physical-phone use and
  the full student acceptance targets remain open. Synthetic transports and
  SQLite checks do not establish PostgreSQL concurrency or live qualification.

## Verification

Focused tests cover explicit disclosure, all retention choices, encryption and
domain/owner binding, scope isolation, off-record RAM-only checkpoint behavior,
completed-turn versus compaction archiving, stale completion and retrieval
fences, source Forget, retained-fact expiry, timed sweep, legacy/native erasure,
sensitive agreement, bounded review handoff, callback wiring in both configured
speech paths and ordinary typed conversation. Root integration records the
exact final command and revision results separately.
