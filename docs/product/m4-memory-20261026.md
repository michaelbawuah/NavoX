# Milestone 4 memory and privacy: source checkpoint

This is an implemented source increment, not acceptance of Milestone 4 or a
claim of live-provider, physical-phone or student qualification.

## Implemented behavior

- Explicit account-scoped disclosure and retention choice: 30 days, 90 days or
  Never. Omitting the choice or agreement cannot enable history. Reading the
  controls never creates a privacy preference or conversation.
- Encrypted completed-dialogue history for configured Vox speech, typed Vox and
  ordinary typed conversation. Source identity, owner, record and purpose are
  authenticated inside ciphertext. Repeated completion does not duplicate text;
  lossy active-call compaction is not archived as a verbatim transcript.
- Independently visible, encrypted saved facts with source provenance, editing,
  deletion and a separate sensitive-detail agreement. Narrow literal learning (described below) never uses model-generated answers
  or creates sensitive facts automatically. Legacy explicit saved preferences remain
  distinguishable and are covered by Delete everything.
- Off-record calls use worker RAM for heard context and store only a content-free
  revision checkpoint. A replacement worker cannot recover private text. Closing
  the worker clears its private cache. Off-record mode also disables archive and
  saved-memory recall. Changing privacy ends the current call to fence provider
  RAM and queued work.
- Bounded permitted recall: key non-sensitive saved facts at realtime start and
  rollover, the same facts on pipeline speech/typed requests, and a shared past
  subject lookup. Historical excerpts come only from student text; past model
  answers are not promoted to student facts. Current saved corrections are kept
  in context even when the query names the old value. Sensitive saved facts stay
  in Settings, and historical excerpts require a spoken privacy notice.
- Ordinary typed conversation uses the same permitted recall and captures its
  privacy generation before provider work. Forget during provider work rejects
  the stale answer and its history write.
- Search/read/delete history. The browser traverses retained history in bounded
  pages, including empty search pages with a continuation, so older conversations
  remain reachable. Private search text and cursors use a POST body, not URLs.
  Cursors bind owner, privacy generation, query and page size and expire; every
  request rechecks the current browser session. The legacy 100-row GET remains
  for compatibility. Saved-fact reads cap at 100;
  voice context caps at 20 facts, one optional thread and three historical matches.
- A natural Forget request prepares a private Settings review, publishing up to
  four metadata matches from at most 100 saved items to the verified browser.
  Saved labels, private History titles, search text and IDs stay out of provider
  tool context; it receives only fixed instructions, bounded counts and coverage.
  The model cannot execute deletion or approve it. The current agent publishes
  the private review handoff under the existing owner checks.
- Source Forget erases transcript, summary and source-derived facts/threads,
  bumps the privacy generation and revokes active media. A content-free source
  tombstone prevents replay. Deleting a source-derived fact also erases
  its source and sibling derivatives after the explicit review. Editing preserves
  its historical transcript and sibling facts, clears its obsolete derived summary
  and makes the corrected fact authoritative. Future recall suppresses that old
  source and its uncorrected sibling facts/threads; History remains readable and
  searchable. Every completed archived turn otherwise has a summary, so a retained
  transcript with no summary is the conservative suppression marker. Manual facts
  have no linked conversation to erase.
- Expiry erases transcripts, summaries and threads while retaining independently
  visible saved facts. The existing independent Vox cleanup process checks a
  bounded expired-owner batch every minute; authenticated history access also
  enforces expiry. Disabling recording or toggling off-record never turns an
  existing 30/90-day expiry into permanent retention.
- Delete everything and student-data reset share the erasure boundary, including
  legacy explicit memory and native assistant sessions. Installed Node runtime
  tables cascade through the native session foreign key in the same database.
  Content-free usage and erasure tombstones remain.

## Bounded automatic learning

Completed retained student turns can now update source-linked facts using closed
literal rules for reply length, tone, study time, programming language, employer
and school. Optional exact Remember that or Actually prefixes use the same rules.
The whole statement must match; questions, quotations, reported speech, conditions,
code, multiple clauses and unknown forms produce no automatic fact. Source text
and turn sequence are preserved. No provider call, new model route, embedding,
raw audio, reminder, calendar change or usage charge is introduced.

Same-category declarations update only automatic facts. Named job departure can
replace an automatic employer only when the named employer matches. Independently
reviewed corrections stay under student control. Old transcripts remain available;
obsolete raw sources are suppressed during future recall.

Recognized literal interview/exam/midterm/presentation/project-review declarations
with today, tomorrow, a weekday or an ISO date can open a thread. Dates use the
student's local date. A generic optional follow-up is eligible only after that
local event date and for seven days afterward. The owner lock durably assigns
one thread to a call/chat context; repeated builds and retries in that context
reuse the same claim, and another context cannot take it. A completed/heard host
answer containing the exact follow-up prompt records responded. Offered-to-model
and host-response receipts are separate; neither proves student delivery or a
successful event. A current exact claim can be released after failure only when
it was never exposed; legacy claims and partial or uncertain exposure remain
consumed.

Sensitive/crisis/credential exclusion is sticky for the source conversation,
including consecutive completed fragments. A later excluded turn removes earlier
automatic facts and threads from that source while preserving independently
reviewed facts and the permitted transcript. Off-record, missing disclosure,
changed generation, source Forget and expired sources prevent learning through
the same archive transaction. Sensitive historical sources are excluded from
voice past-context lookup.

## Open implementation and qualification

- This is conservative literal learning, not arbitrary semantic/model extraction.
  Unsupported statements require the explicit Settings fact flow. General open
  questions and arbitrary automatic extraction in ordinary typed conversation
  remain future work under its versioned answer-only contract. Reviewed Vox
  candidates are implemented below. No unqualified or unpriced model route is
  enabled.
- Keyword sensitivity checks are conservative guardrails, not a comprehensive
  classifier. No automatic sensitive-fact extraction is claimed.
- A separately configured Node runtime database requires its own erasure and
  retention qualification. The native same-database cascade does not establish
  cleanup of an independent database.
- The non-configured legacy one-off voice gateway is not the configured
  cross-call memory path. Raw audio is never added to these memory tables.
- Live model behavior, spoken privacy-warning adherence, physical-phone use and
  the full student acceptance targets remain open. Synthetic transports and
  SQLite checks do not establish PostgreSQL concurrency or live qualification.

## Versioned semantic selection and private suggestions

The new `learn_completed_memory` native tool selects exact spans from the last
eight bounded, completed student messages in the current retained call. It runs
inside the existing metered native tool loop and uses its normal complete-request
reservation; it does not create a new provider route. Current/unarchived speech
and a final turn without a later learning opportunity are not claimed as learned.
The existing configured/priced Vox admission and current disclosed retention are
required. The separate background flag is not a prerequisite for this native path.

The host checks each quote against the actual archived student source. Only whole
independent neutral sentences certified by the existing closed host grammar can
update ordinary facts or supported dated threads. Every sentence of the entire
parent message must independently certify as a direct neutral declaration or
supported event; mixed/unknown parents cannot launder an inner first-person quote.
Negation, quotation, reported-speech, conditional, sensitive and crisis guards
also apply. Model categories confer no privacy authority. General unknown semantics
become encrypted private suggestions, never automatically voice-readable facts.
The model can select an extractive summary from exact student quotes, not invent
summary prose, progress, dates or approval. Delayed results use source observation
order and cannot replace newer category facts, reviewed corrections or summaries.
Each archived exchange captures its timezone in encrypted transcript metadata;
the source-prefix proof binds that recorded zone. Later profile timezone changes
cannot redate a relative event. Legacy turns without a recorded timezone can
still certify date-independent neutral facts, but cannot create semantic threads.

`GET /memory/learning` privately lists up to twenty owned suggestions with truthful
bounded scan status. `enabled` means current disclosed recording is active;
`configured` reports read-only native/background route readiness, not activation of
background traffic. Existing suggestions remain reviewable without a configured
background gateway. Confirm requires the current generation, explicit `SAVE MEMORY`
and separate private-detail agreement. It stores one exact source-linked private
fact, suppresses its whole source from voice recall and invalidates active native
contexts while keeping History readable. Matching retries read only the original
receipt; edits, deletion, expiry and further privacy changes cannot recreate it.
The existing five-minute Vox candidate proof and private topic remain unchanged.

Optional background extraction has its own `conversation_memory_learning@v1`
prompt/schema, `EXTRACT` / `EXTRACTION_HIGH_ACCURACY`, PERSONAL sensitivity and
text/structured-output requirements. `MEMORY_SEMANTIC_LEARNING_ENABLED` defaults
false and controls only this background queue/worker. A published catalog, explicit
scope/grants, current model evaluation for this exact contract, credentials, known
prices and cost bounds are required; the ordinary typed v1 answer-only contract is
unchanged. There is no fallback to native/provider HTTP when that gateway is disabled.
Background attempts have no shadow or cross-provider fallback, cost at most the
operator ceiling or USD 0.05 per job, and cap at ten background claims per owner in
a rolling day. A claimed/uncertain attempt is never automatically submitted again.
Run its optional consumer with `python -m navox.memory.worker` after qualification.

Migration 0065 adds content-free job metadata and encrypted pending output; input
text stays solely in the retained source and worker RAM. Owner/purpose-bound HMAC
proofs bind the exact source prefix. Private suggestions expire within seven days
and before source expiry. The independent cleanup worker also erases expired jobs
when a source uses Never retention. Source expiry, Forget, reset, correction and
privacy changes explicitly clear proposal ciphertext even when lineage rows remain.
Populated queue/review data blocks downgrade under an exclusive PostgreSQL lock.
Fixture tests do not qualify live background models, speech or physical devices.

## Verification

Focused tests cover explicit disclosure, all retention choices, encryption and
domain/owner binding, scope isolation, off-record RAM-only checkpoint behavior,
completed-turn versus compaction archiving, stale completion and retrieval
fences, source Forget, retained-fact expiry, timed sweep, legacy/native erasure,
sensitive agreement, bounded review handoff, callback wiring in both configured
speech paths and ordinary typed conversation. Root integration records the
exact final command and revision results separately.

## Reviewed candidates and enforced output boundaries

The existing metered Vox tool loop can prepare a review of one exact complete
student statement from an earlier completed exchange in the same retained call.
It cannot infer provenance, select another source or save a fact. An encrypted
five-minute proof binds call, authenticated login, owner, privacy generation and
the exact archived turn. Only the verified browser receives the quote/proof.
Settings requires explicit Save confirmation and a separate unchecked agreement
for private details. Unknown semantics default private rather than trusting a
model classification; they stay out of voice recall, including after edits.

Confirmation rechecks all source/privacy/session fences. Exact retries recover
only a matching saved receipt and cannot overwrite corrections or recreate
erased data. Real native hang-up is supported before confirmation. Saving a
private candidate withdraws its whole source from voice excerpts, summaries,
threads and sibling facts while preserving readable transcript History. Privacy,
source Forget and corrections invalidate loaded voice context and this owner's
active native assistant sessions, including same-database cached turns; other
owners and content-free operational receipts remain intact. Independent Node
databases still need their separate retention/erasure qualification.

Historical speech uses a host-enforced prospective privacy notice. Pipeline
speech prefixes its existing metered synthesis; realtime can use a metered
host-speech prelude when that qualified path is configured. Warmup stays
silent. Without that qualified speech path, protected historical context is
withheld. Generic notice audio cannot alter provider PCM interruption timing or
arm a calendar approval. Source/call authority is rechecked through output;
fixture playout ordering does not prove physical audibility.

Follow-up claims are versioned and are not consumed by silent warmup. Exposure
is recorded before output; an exact unexposed claim can be released after a
failed/abandoned turn. Partial or uncertain output is never reset merely by a
timeout. Typed answers record exposure with the validated answer/archive before
returning JSON, and release exact unreturned offers on failure. Potential
exposure, host response and actual student delivery remain distinct evidence.
